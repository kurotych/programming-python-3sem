## База даних

Одна таблиця, створюється при старті:

```sql
CREATE TABLE IF NOT EXISTS notes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    text TEXT NOT NULL,
    created_at TEXT NOT NULL
)
```

`created_at` заповнюється в Python: `datetime.now().strftime("%Y-%m-%d %H:%M")`.

## Поведінка

**Старт.** Підключитись до бази, створити таблицю, за потреби додати три власні нотатки, після чого відмалювати вміст бази у вікні.

**Оновлення вигляду.** Зробити один метод `refresh()`, який:

1. Читає всі нотатки: `SELECT created_at, text FROM notes ORDER BY id`.
2. Формує рядки виду `<created_at>  <text>` і показує їх у `preview_label`, з'єднавши через `"\n"`. Якщо база порожня — `No notes yet`.
3. Оновлює `counter_label` на `Notes: <кількість>`.

Цей самий метод викликається після кожної зміни бази — окремої копії нотаток у пам'яті класу тримати не треба.

**`add_button`.** Якщо `note_field` порожнє (перевіряти `.strip()`) — нічого не робити. Інакше `INSERT` нового рядка з поточним часом, `commit()`, очистити `note_field` і викликати `refresh()`.

**Закриття.** Перевизначити `closeEvent()` і закрити підключення:


!!! danger "Параметри запитів"
