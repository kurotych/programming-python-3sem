## Завдання 5. Арифметика

Арифметична операція над масивом виконується **для кожного елемента** одразу, без циклу: `a * 2` множить на 2 кожне число масиву. Нижче aᵢ — i-й елемент масиву `a`.

Масив із завдання 1 збережіть у змінну `a`. Виведіть по черзі:

1. `a * 2` (aᵢ · 2) — кожне число, помножене на 2;
2. `a + 10` (aᵢ + 10) — до кожного числа додано 10;
3. `a ** 2` (aᵢ²) — квадрат кожного числа;
4. `a / N` (aᵢ / N) — кожне число, поділене на `N` (зверніть увагу: результат стає дробовим);
5. суму квадратів (a₁² + a₂² + … + aₙ², тобто Σ aᵢ²; тут n = N).
