## Завдання 1. Система рівнянь

Розв'язати систему:

$$
\begin{cases}
2x + y - z = N \\
x + 3y + 2z = 2N \\
3x - y + z = 10
\end{cases}
$$

1. Записати матрицю коефіцієнтів `A` і вектор `b`.
2. Знайти розв'язок через `np.linalg.solve` і вивести його.
3. Перевірити: вивести `A @ x` та результат `np.allclose(A @ x, b)`.

Приклад для `N = 7`:

```text
[3.4 2.2 2. ]
[ 7. 14. 10.]
True
```

## Завдання 2. Матриці

Для матриці `M = [[N, 2], [1, 3]]` вивести:

1. `M * M` і `M @ M` — і в коментарі одним реченням пояснити різницю;
2. визначник, округлений до 2 знаків;
3. обернену матрицю;
4. перевірку, що `M @ inv(M)` дорівнює одиничній матриці (`np.allclose` + `np.eye`).
