## Завдання 1. Система рівнянь

Розв'язати систему через `np.linalg.solve`:

$$
\begin{cases}
2x + y = 5 + N \\
x + 3y = 10 + N
\end{cases}
$$

Вивести:

1. розв'язок `[x, y]`;
2. добуток `A @ solution` — має вийти права частина;
3. перевірку через `np.allclose`.

```text
[3.8 4.4]
[12. 17.]
True
```

## Завдання 2. Операції з матрицею

Для матриці

```python
M = np.array([[N, 2], [1, 3]])
```

вивести:

1. транспоновану матрицю;
2. `M @ M`;
3. визначник, округлений до 2 знаків;
4. обернену матрицю;
5. `M @ inv`, округлений через `np.round(..., 10)` — має вийти одинична матриця.
