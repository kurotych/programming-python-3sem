## Завдання

Замінити список нотаток (`QListWidget` із практичних 7–8) на **таблицю `QTableView` з власною моделлю** над спільним `AppState`.

Обов'язкові вимоги до результату:

- дані нотаток існують **в одному екземплярі** — у `AppState`; модель копії не робить;
- усі зміни нотаток проходять через методи стану, модель лише перекладає виклики;
- `QListWidget`, `QTableWidget` і `QStandardItemModel` у проєкті **не використовуються**;
- номер рядка ніде не є ідентифікатором нотатки — тільки `note.id`;
- зміна однієї нотатки не скидає модель, не втрачає виділення й позицію прокрутки;
- усі відкриті головні вікна показують ті самі дані одночасно.

## Персоналізація

Константи, як і раніше, живуть тільки в `app/config.py`. До наявних додаються три нові:

```python
STUDENT_NAME = "Ivan Petrenko"                # ваше ім'я та прізвище транслітерацією
STUDENT_GROUP = "KI-31"                       # ваша група
DB_FILE = "workspace_ivan_petrenko.db"        # файл бази з практичних 3-5
APP_TITLE = "Notes Manager"                   # назва застосунку
TABLE_PREVIEW_LENGTH = 40                     # символів тіла нотатки в колонці Preview
LONG_NOTE_CHARS = 200                         # від якої довжини нотатка вважається довгою
EMPTY_TABLE_TEXT = "No notes to show"         # текст, коли таблиця порожня
```

Заголовки вікон і команди з практичної 8 лишаються без змін.
