## Завдання

Написати скрипт `plots.py`. Кожне завдання створює **окрему фігуру** і зберігає її у файл `task_1.png`, `task_2.png`, ... через `fig.savefig(..., dpi=150)`. Наприкінці скрипта — один `plt.show()`.

## Персоналізація

```python
STUDENT_NAME = "Ivan Petrenko"   # ваше ім'я та прізвище транслітерацією
STUDENT_GROUP = "KI-31"          # ваша група
N = 7                            # ваш номер у списку групи + 5
```

У заголовку графіка завдання 1 має бути ваше ім'я та група.

Генератор випадкових чисел: `rng = np.random.default_rng(N)` — один раз на початку скрипта.

## Завдання 1. Лінійний графік

1. Створити `x = np.linspace(-10, 10, 100)`.
2. На одному графіку побудувати дві лінії: `y = x ** 2` і `y = N * x`.
3. Перша лінія — суцільна, друга — пунктирна (`linestyle="--"`). Додати легенду з підписами `"x^2"` і `"N*x"`.
4. Увімкнути сітку (`ax.grid(True)`).
5. Заголовок графіка — ваше ім'я та група, наприклад `"Ivan Petrenko, KI-31"`.

## Завдання 2. Температура

Придумайте середню температуру за 12 місяців для свого міста.

1. Побудувати лінійний графік із маркерами `"o"`.
2. На осі x підписати місяці: `"Jan"`, `"Feb"`, ... (`set_xticks` + `set_xticklabels`).
3. Додати горизонтальну пунктирну лінію середньорічної температури з підписом у легенді.

## Завдання 3. Стовпчикова діаграма

## Завдання 4. Гістограма

3. Вертикальними лініями позначити середнє та медіану (різні кольори, легенда).

## Завдання 5. Scatter

3. У консоль вивести коефіцієнт кореляції `x` і `y` (2 знаки).
